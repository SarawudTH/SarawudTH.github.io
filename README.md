# sarawudsaleesongsom.com

Personal academic website of Sarawud (Juy) Saleesongsom, hosted on GitHub Pages.

- `index.html` — the whole site (one page, all CSS/JS inline)
- `CNAME` — tells GitHub Pages which custom domain to serve

To update the site, edit `index.html` and commit; GitHub Pages republishes within a minute or two.
